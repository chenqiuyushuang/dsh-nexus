# V0.8.1 面板 B：四路专家评审 + 修复记录

用户问「找个 UI 专家看看这个页面有啥问题」，于是请了四路专家各自独立评审（可用性总评、视觉设计、
交互 HCI、无障碍 WCAG、窄屏约束），全部基于源码 + 418×448 实测 + 实拍图。
本文件记录**他们查出的问题**与**已修的部分**。

## 二、四个真 bug（专家实测发现，已修）

1. **遮罩层规则在移植时整段丢失** → 面板根本不是浮层（无遮罩、无 z-index、「点面板外关闭」是死代码、
   状态条 + 92vh 造成 7px 文档溢出 + 两条滚动条）→ 补回 `position:fixed;inset:0` 遮罩，面板高度用可用高。
2. **菜单与二级弹窗的 portal 落在样式作用域之外**（`createPortal(…, document.body)`，而样式是 `.nx-b .menu-popup`）
   → 实测 `position:static`、`rect y=448`（视口外），**编辑/新增/关联/置顶/归档/移入回收站/复制 ID 一个都点不到**。
   改为 portal 到 `.nx-b` 根节点；实测菜单现在 `position:fixed`、`y=188`、在作用域内、6 项可点。
3. **归因分组不互斥**：同一条记忆同时出现在「进入上下文」与「模型推断」，字节被重复计（两组都 603 B，预算 1024 B）
   → 改成互斥三组，来源改成组头上的分布提示。
4. **首次加载失败显示全 0 假状态**（「0 条进入上下文 / 0 B / 0 条待确认」）
   → 改成「记忆加载中…」/「记忆读取失败 · 点此重试」，不渲染任何数字。

## 四、其余已修

- **对比度**：`--text-3` `#5E5E6A` → `#9096A2`（面板 5.44 / 卡片 5.09 / 标题带 4.58），
  并加对比度测试锁住；`.btn-add-new` 白字底 `#3B82F6`(3.68) → `#2563EB`(5.17)。
- **可达性**：面板加 `role=dialog aria-modal`；标签页 `role=tablist/tab + aria-selected`；
  分组头与记忆库行改 `role=button tabindex=0 + aria-expanded` 并支持 Enter/Space；补回 caret（原来只有 CSS 没渲染）；
  状态条支持空格 + `aria-expanded/aria-controls`；⋯ 加 `aria-label`（原来 9 个都叫「⋯」）并常显；
  置信度未知不再画红点；toast/横幅加 `role=status aria-live`；全局 `:focus-visible` 轮廓；滚动条提亮。
- **交互**：Esc 关面板/菜单/弹窗（真实键盘事件实测有效）；点遮罩关闭；菜单按触发按钮锚定（原来写死 `{x:40,y:120}`）；
  菜单项改 `<button role=menuitem>`；模式圆点只表模式（原来 noise>0 会盖掉「已关闭」）；批量归档/入回收站补撤销；
  `run()` 返回 boolean，**失败不再清空选择**；回收站「彻底清空」加二次确认。
- **视觉**：卡片改 `--bg-card`（原来比容器更暗，像凹陷）、组头做标题带、
  边框接宿主 `rgba(255,255,255,.12)`（原来 1.15:1，卡片没有形体）、字号接 `--nx-content-font-size`、全局 `tabular-nums`。

## 五、还没做（下一轮候选）

- 橙色语义超载（6 处）与绿/红方向不一致（模式 / 数据质量 / 生命周期三套语义挤在一组颜色里）。
- 模式三态把「记录」×「注入」两个正交开关压成互斥三选一；「只看不记」的 active 看着像 disabled。
- 预算条画的是作用域构成却被读成预算进度；建议改成真进度或三个 inline chip。
- 切标签页不重置滚动位置；空态不区分「筛掉了」与「本来没有」。
- 与 DSH 亮色主题的适配（面板是硬编码暗色，宿主切亮色时是一块黑卡）。
- 高度自协商仍是死代码（`desiredHeight()` 还在读旧面板的 `.nx-app/.nx-list`）。
