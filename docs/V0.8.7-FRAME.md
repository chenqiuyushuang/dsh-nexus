# V0.8.7 面板铺满与最外圈边框（确认 + 保留）

用户两点：
1. panel-body 高度不够、实际上还没到底？
2. 最外面的边框还是要留着的。

## 1. panel-body 到底了（实测）

面板是「模式行 + 标签行 + 内容区」三段的 flex 列：

| 区块 | 高 |
|---|---|
| 模式 + 预算行 | 53 |
| 标签行 | 41 |
| **内容区 panel-body** | **526**（iframe 620）／**806**（iframe 900） |
| 面板总高 | 620 ／ 900（= iframe 高，左右与 iframe 同宽） |

53 + 41 + 526 = 620 —— 内容区吃满剩余高度，底部没有空余；
文档溢出 0、面板矩形与 iframe 完全一致。

（之前看起来没到底，是两层表面造成的错觉：遮罩那层 8px 内边距 + 面板自己的圆角，
在面板与 iframe 之间露出了一圈底色。0.8.6 把表面统一到根节点后这圈就没有了。）

## 2. 最外圈的边框：保留，并且它在根节点上

现在的外框来自 .nx-b.panel-open（面板打开时的根节点）：

    .nx-b.panel-open {
      background: var(--bg-panel);
      border: 1px solid var(--border-frame);   /* #33333A，不透明 */
      border-radius: var(--radius);            /* 8px */
      box-shadow: 0 24px 60px rgba(0,0,0,.6);
      overflow: hidden;
    }

也就是说：**圆角 + 边框 + 阴影都在最外那一圈上**，面板内容不再有第二层边框。
如果觉得太淡，把 --border-frame 调亮一档即可（例如 #3F3F48）。
