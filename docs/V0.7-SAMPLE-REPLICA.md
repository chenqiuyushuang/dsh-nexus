## 只有 5 处偏离样例（都是物理约束或真实数据导致，已在 CSS 文件头备查）

1. `.modal{width:780px}` → `width:100%; max-width:780px`：DSH 设置弹窗内容区实测 418px，写死会被裁。
2. `body` 级规则 → `.nx-replica` 自身：面板是 iframe 里的一个 div，不是整页。
3. 变量作用域 → `body[data-ds-dark-theme]`：跟随 DSH 主题开关（样例是 `:root`/`body.light`）。
4. `.content > * { flex-shrink: 0 }`：样例只有 4 条数据看不出来；真实库 34 条时，
   列表会把设置条压成 2px（实测），必须禁收缩。
5. `.list-container{max-height:52vh; overflow-y:auto}` + 一页 50 条 + 「加载更多」：
   样例 4 条数据不需要分页；真实库几十条时不限制会让模态长到 3000px。
   （保留了样例的 `min-height: 200px`，列表下限没动。）
