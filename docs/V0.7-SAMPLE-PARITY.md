用 `scripts/style-diff.mjs` 把**样例 HTML** 和**面板**放进同一个 780px 宽的 iframe，
同一次运行里读 `getComputedStyle`，逐项对比（不是目测）：

```bash
node scripts/style-diff.mjs        # 输出 { sample: {...}, panel: {...} }
node scripts/ref-shot.mjs          # 样例自身截图 + 关键盒模型（828×772，DPR=2）
```

## 唯一无法靠改代码解决的

**宽度**。DSH 设置弹窗的内容区实测 418px，样例是 780px（1.87 倍）。
面板不能自己变宽——除非改 DSH 源码（用户明确不允许）。所以：
- 设置面板里：紧凑档（7px/10px 内边距、96px 行高、一屏 2–3 条）
- 独立页 `/nexus`（全宽）：`.reference-scale` 档 = 上表全部 ✅

## 还没做、需要你定的三件

1. **噪音横幅**：DSH 特有（样例里没有）。现在占 32px。
   要不要收成进度卡右边的一个小徽标（"27 条疑似无效"），点开才展开？
2. **标题栏**：样例有「记忆设置 + 🌙 主题切换 + ✕ 关闭」。
   独立页可以照做（标题 + 主题切换）；设置弹窗里 DSH 自己已有导航和关闭，
   再放一个就是两个关闭按钮——建议只在独立页加。
3. **底部按钮**：样例固定「确认并应用全局修改」。
   现在是"阈值真改了才出现"（固定一个没有任何改动的按钮等于装饰，还占 52px）。
   要不要改成常驻但禁用态？
