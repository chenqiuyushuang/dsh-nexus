# V0.8.5 面板高度对齐 Agent 预设：去掉二次压缩，改用宿主真实可用高

用户对比了「Agent 预设」页与「记忆」页：Agent 预设的面板**填满整列**，记忆面板只在上面一段，下面留空。

## 两处原因（都实测过）

1. **面板在被宿主裁过一次的高度上又乘了 0.92**
   `.panel{max-height: min(92vh, ...)}` —— iframe 是 620 时，92vh = 570，于是底部稳定留 50px 空。
   → 去掉 92vh，改成 `max-height: var(--nx-b-available, 100%)`（宿主把可用高写进这个变量；没写就吃满 iframe）。
2. **可用高本身报小了 + iframe 上限 620 太紧**
   `src/client/index.ts` 原来发的是父容器的 `clientHeight`（面板一长高父容器也长高 → 自反馈抖动），再减 24；
   iframe 的 `maxHeight` 也卡在 620。而 DSH 设置弹窗内容列实际比这更高（Agent 预设能铺满就是证据）。
   → 改成 `Math.max(父可视高, 视口高-220, 320) - 16`，iframe 上限 620 → **1000**（宿主仍按自己的可用高裁剪）。

## 实测（iframe 418×620）

| 元素 | 改前 | 改后 |
|---|---|---|
| 面板高 | 570 | **604**（= 620 − 2×8 遮罩内边距） |
| 面板 `max-height` | min(92vh, …) | var(--nx-b-available, 100%) |
| 内容区高 | 474 | **508** |
| 文档溢出 | 0 | 0 |

在真实宿主里，面板高度 = 宿主给的可用高（`--nx-b-available`），也就是与「Agent 预设」同高；
iframe 上限提到 1000 后，设置弹窗越高面板就能越高。
