## 1. 面板是什么

- 位置：DSH Web GUI → 设置弹窗 → 第 5 项「记忆」→ 内容区是**内嵌 iframe**（`/nexus`）
- 技术：React（`src/ui/NexusPanel.tsx` + `components.tsx` + `theme.css`），构建时打成单文件 HTML（`lib/nexus.html`，178KB），无外部依赖、无 UI 框架
- 同一页面也可独立访问 `http://127.0.0.1:3080/nexus`
- 中文文案；面板容器约 1080×700，可能更窄

## 2. 现有能力（读代码核对）

| 区域 | 现有内容 |

## 3. 已知问题（专家团前一阶段实测，供你诊断用）

1. **列表上限 80 且客户端过滤**：筛选「待确认」时若库里 >80 条会静默漏报（`web-ui.ts` limit=80 + `NexusPanel` 前端 filter）；
2. **回收站语义弱**：删除 = `archived`，与系统归档混在一起，无独立回收站视图；
3. **置顶反噬**：置顶条数多会把其他记忆挤出 1KB 注入预算，面板无占用提示；
4. **危险操作确认**：彻底清除用 `window.confirm`（原生弹窗，样式割裂）；
5. **状态标签是内部术语**（personal/reference/needs-review 的映射已中文化，但"槽位 vs 作用域"对用户仍抽象）；
6. **无批量操作**、**无撤销**、**无键盘流**；
7. **决策日志与列表割裂**：被拒记录只能看，不能"我现在就想记住它"（无反向操作）；
8. **iframe 内滚动/高度**：`/nexus` 在设置面板里是 72vh iframe，独立访问时是整页。

## 4. 产品承诺（设计不得违背）

- 零配置可用、**不烧 token**（面板不做任何 LLM 调用）；
- 记忆是**数据**：面板必须让用户随时**看清 / 改对 / 撤掉**；
- 作用域隔离是核心：用户要能一眼看出"这条会不会跨项目"；
- 系统只归档、用户删除走回收站、彻底清除才真删。
