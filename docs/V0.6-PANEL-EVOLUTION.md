展开后：**原文块 → 冲突/重复对照（有才显示）→ 详情网格（ID/作用域/类型/权重/置信度/占注入/更新时间）**。

## 2. 必要的偏离（都是实测逼出来的，不是审美取舍）

| 参考稿 | 面板 | 实测依据 |
|---|---|---|
| 绝对尺寸（卡片 16px 内边距、14px 行内边距、`.list-container{min-height:200px}`） | 窄栏紧凑档（8–10px / 7px / 无 min-height） | 418×448 里照抄 → 首屏一条记忆都看不到 |
| 状态卡"标签在上、大数字在下"两行 | 同卡内联（`在用 4`） | 一屏省 22px 给列表，信息不减 |
| 列表容器固定 `min-height:200px` | 窄栏下 `flex:1 1 auto; min-height:0; overflow-y:auto` | flex 子项默认 `min-height:auto` 会被内容撑开 → 实测列表长到 542px、头部滚走 |
| 裸百分比进度条 | 真实字节（`注入 2 条 / 603 B（预算 1024 B）`） | 参考稿的 25%/75% 是手写死的示例值 |
| 面板内主题开关 🌙 | 跟随 DSH 主题 | 多一个开关只会不同步 |
| 右下角固定大按钮 | 有改动才出现的 `.nx-footer-bar` | 固定占位会把列表压到 0 高（v1 实测） |

## 3. 本轮踩到并修掉的 4 个布局坑

1. **flex 子项 `min-height:auto`**：`.nx-listcard` 被内容撑到 542px → 头部滚走。修：`min-height:0` + 列表 `overflow-y:auto`。
2. **网格行里子元素的 padding 撑破 `0fr`**：`.nx-disclosure-inner{padding:...}` 让每条收起行多 10px 白条。修：padding 移到再内一层（`.nx-row-details-inner`）。
3. **副信息换行**：`.nx-row-sub` 允许 `flex-wrap` → 行高从 90 涨到 106。修：`nowrap` + 省略。
4. **分段条比例不生效**：`flex:1 1 0` 让三段等宽。修：`flex-grow:ratio; flex-basis:0`。

## 4. 定稿实测（418×448，`--fixed` 宿主拒绝长高）

| 区域 | 高 |
|---|---|
| 占用卡 | 115 |
| 状态卡 | 35 |
| 工具栏 | 44 |
| 列表容器 | 208（表头 30 + 列表 178，可滚动） |
| 条目 | 96（两行标题 45 + 副信息 18 + 间距/内边距） |

`html/body/.nx-app = 448`，`docOverflow = 0` —— 外框不滚，只有列表滚；占用卡/状态卡/工具栏永远可见。

## 5. 沿用 0.6.0 的交互增强（参考稿也有的部分）

- Grid 行展开动画（`grid-template-rows: 0fr↔1fr`）+ 收起时 `inert`
- 右键上下文菜单（与行内「⋯」共用菜单项）
- Shift 连选 / Cmd 加选 / ↑↓ 键盘焦点环 / 空格勾选
- 置信度圆点（`--nx-conf-high/mid/low`，非文本对比 ≥3:1）
- 错误态「点击重试」、Toast 撤销
