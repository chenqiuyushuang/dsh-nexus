# V0.6 面板外壳：参考稿落地记录

用户给了两版参考 HTML（`_shots/reference-modal.html` v1 / `_shots/reference-modal-v2.html` v2），
本文件记录**哪些落地、哪些不落地、依据是什么**。所有数字都是`scripts/ref-compare.mjs`与
`scripts/panel-preview.mjs`在真实窄栏（418×448）里量出来的，不是估算。

复现：

```bash
node scripts/ref-compare.mjs --width 418 --height 448                              # 参考稿 vs 当前面板
node scripts/ref-compare.mjs --width 418 --height 448 \
  --ref _shots/reference-modal-v2.html --tag v2at418                               # 参考稿 v2
node scripts/panel-preview.mjs --dark --font 14 --stub-state --nav --out _shots/x.png
```

## 1. 为什么不能照抄：参考稿在真实宽度下的实测

参考稿是给 780px 独立弹窗设计的（`body{overflow:hidden}` + `height:100vh` + 硬编码色值）。
放进 DSH 设置弹窗的窄栏后：

| | 参考稿 v1 @418 | 参考稿 v2 @418 | 当前面板 @418 |
|---|---|---|---|
| 首屏有记忆条目 | ❌（列表在折叠线下） | ❌（列表 top 394，视口 448 且被固定 footer 压住） | ✅ 4 条 |
| 设置条 | 2px（标题不可见） | 2px（标题不可见） | 标题常驻 60px、表单 232px |
| 横向溢出 | 429 > 418（标题被裁） | 0 | 0 |
| 固定底部按钮 | 把列表挤到 0 高 | 压住搜索框 | 无 |

**结论：卡片化（97px 占用卡 + 79px 状态卡 = 首屏 39%）是用"看不到记忆"换"看着讲究"。**
记忆面板的第一功能是看记忆，所以布局层不照抄。

另一个不能抄的理由：参考稿的「未进入 31 条」是把 27 条已归档算进去的旧 bug（0.5.7 已修），
「冲突 2」的标签也是错的（那 2 条是**待确认**）。照抄会把错误语义固化。

## 2. 落地的四项（v0.6.0）

### 2.1 Grid 行展开动画（抄 v1 的 `grid-template-rows` 技法）
```css
.nx-disclosure { display: grid; grid-template-rows: 0fr; transition: grid-template-rows .22s ease; }
.nx-disclosure.open { grid-template-rows: 1fr; }
.nx-disclosure-inner { overflow: hidden; min-height: 0; }
```
- 取代原来 `max-height: 96px` 的夹高：Grid 由浏览器按内容求解，收起到 0、展开到自然高度，两帧都精确。
- **内层必须 `overflow:hidden; min-height:0`**，否则 0fr 塌不下去。
- **子元素的外边距会撑破 0fr**（内层 min-content 变大）→ 边距一律移到内层容器的 padding。
- 收起时给内层加 `inert`：只做视觉隐藏的话，内容仍在可访问树里、Tab 还能摸到。
- 展开区保留 `max-height: 96px` 的内部滚动（长记忆 400 字在窄栏是一面文字墙）。

### 2.2 设置区常驻折叠条（抄 v1/v2 的 settings-panel）
- 面板里设置**标题永远可见**，点标题整条展开，箭头旋转 180°。
- 窄栏特例：`html.embedded .nx-settings:not(.open){display:none}`。
  常驻折叠条要 44px 触摸目标（实测 60px），等于 3 行列表 —— 窄栏里不划算；
  宽屏（独立 /nexus 页）保持常驻。
- 展开时限高 260px + 内部滚动，不把列表压到 160px 最小高度以下。

### 2.3 右键上下文菜单（抄 v2 的 context-menu）
- 菜单项**只写一份**（`menuItems`），行内「⋯」与右键菜单共用 —— 两处行为不一致是这类菜单最常见的 bug。
- portal 到 `document.body`：列表有 `overflow` 与 `content-visibility`，留在行内会被裁。
- 坐标夹取到视口内；点击他处 / 滚动 / 缩放 / Esc 关闭。

### 2.4 Shift 连选 + 键盘导航焦点环（抄 v2 的多选与 `.focused`）
- 勾选框：Shift 从上次点击处连选，Cmd/Ctrl 加选（`title` 里有提示）。
- 面板级 ↑/↓（或 j/k）移动焦点环，空格切换勾选，Esc 清焦点；输入框里不抢键。
- 焦点环 = `inset 2px` 实心条 + 边框色，非文本对比已进 `tests/contrast.test.ts`。

## 3. 顺带修掉的三件事

1. **置信度圆点**（参考稿的 `confidence-dot`）：折叠行左侧 8px 圆点，高/中/低三档。
   颜色不是唯一载体：`title` 与 `aria-label` 给百分数（WCAG 1.4.1）。
   新增 `--nx-conf-high/mid/low`：绿-500、琥珀-500、红-500 在白底只有 2.3/2.15/3.4:1，
   非文本对比要 ≥3:1，所以亮色改用 green-900 / amber-700 / red-700（与作用域色条同因同解）。
2. **错误态重试按钮**：原来加载失败只有一行字，没有出路。
3. **窄栏数字输入框去掉放大镜**：阈值输入框复用 `.nx-search` 类，继承了背景图标。

## 4. 明确不抄

| 参考稿做法 | 不抄的理由 |
|---|---|
| 卡片化占用卡 + 4 张状态卡 | 176px = 首屏 39%，换来的信息我方一行 chip 就装得下 |
| 固定底部「确认并应用全局修改」 | 448 高里会把列表挤没（已实测） |
| 百分比进度条（用户 25% / 项目 75%） | 参考稿是手写死的比例；我方算的是真实字节（603 B / 1024 B） |
| 面板内主题开关 🌙 | 面板跟随 DSH 主题自动切换，多一个开关只会不同步 |
| 骨架屏 | 列表是服务端分页查询，「加载中…」是诚实态，不是占位 |
| UUID 露在标题里 | 正是我方判定为垃圾并拒收的那类内容 |
| 右键菜单替代「⋯」 | 只做加法：`⋯` 保留（键盘与触屏都要用），右键是加速通道 |

## 5. 实测数据（418×448，`--fixed` 宿主拒绝长高）

| 场景 | 面板高 | docOverflow | headerTop | 列表高 | 可见行 |
|---|---|---|---|---|---|
| 默认（含噪音横幅） | 548 | 16 | 28 | 160 | 3–4 |
| 宿主允许长高 | 620（上限） | 0 | 28 | 316 | 5 |
| 展开一条长记忆 | 548 | 16 | 28 | 160 | — |
| 打开设置 | 548 | 258 | 28 | 160 | 4 |

重点：**headerTop 恒为 28（头部不滚走）**，展开态不再把面板顶到 1345px 那种失控高度。
「打开设置」时 docOverflow 258px 是用户主动展开的代价（设置表单 + 260px 限高滚动区），可接受。
