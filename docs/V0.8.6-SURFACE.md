# V0.8.6 面板与 iframe 合成同一张表面 + 高度铺满

用户两点：面板还是矮一截；还是直角 —— 感觉 iframe 是 iframe、面板是面板，不是一个，能用一个吗？

## 一、为什么之前不是一张表面

原来是两层：遮罩「.overlay」（半透明黑底 + 8px 内边距 + 圆角）+ 里面的面板卡片（深色底 + 圆角 + 阴影）。
两层背景必然出现外圈暗边 + 内层直角的分裂感。

### 改法：表面只放在根节点上

- 面板打开时给根节点 .nx-b 加 .panel-open：背景 var(--bg-panel) + 圆角 8px + 边框 + 阴影，它自己就是那张卡；
- .overlay 变成完全透明的点击层（只负责点外部关闭与铺满可用高），不再画背景/圆角；
- .panel 背景透明、无边框、无圆角 —— 与根节点同一张表面；
- 新增不透明的 --border-frame 给外框（原来 rgba(255,255,255,.12) 压在同色底上几乎看不见）。

## 二、高度：现在是铺满（实测）

| iframe 高 | 根节点 | 遮罩 | 面板 | 内容区 | 文档溢出 |
|---|---|---|---|---|---|
| 620 | 620×418 | 620×418 | 620×418 | 526 | 0 |
| 900 | 900×418 | 900×418 | 900×418 | 806 | 0 |

面板矩形与 iframe 完全一致（左对齐、无底部空档），内容区随高度伸展。

高度链路累计修了三处：
1. 去掉 .panel{max-height:min(92vh,…)} 的二次压缩；
2. .panel{height:100%} + 遮罩 align-items:stretch；
3. 可用高改由 src/client/index.ts 上报（Math.max(父可视高, 视口高-220, 320) - 16），iframe 上限 620 → 1000。
