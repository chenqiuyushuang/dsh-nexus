# Nexus v0.6 专家团评审简报（共享事实基线）

> 仓库：`/Users/chenqixing/Desktop/DSH-Nexus Memory System`（只读评审）｜产品：DeepSeek Harness (DSH) 的记忆层插件 `@chenqiuyushuang/dsh-nexus`
> 目标读者：15 位大模型 / Harness 专家。所有结论请以本简报 + 源码为准，注明证据（文件:行号 或实测命令）。

## 1. 产品承诺

1. **零配置可用**：默认不调用任何模型（0 token / 0 网络），`dsh plugin add` 一条命令即用；
2. **成本自保**：注入 ≤1KB × 每会话一次；提炼有硬预算闸门；7 天无使用自动降级为只写不读；
3. **分层隔离**：作用域 user / project / episode；项目记忆只在同 projectRef 注入，unknown 永不注入；
4. **数据非指令**：注入块带声明 + 内容扁平化，记忆永远当数据不当指令；
5. **可回溯**：系统只归档；用户删除走回收站 → 彻底清除；归档即黑名单（同句不复活）。

## 3. 关键实测数据（可复核）

- 检索：500/2000/5000 条 = **1.8 / 5.1 / 10.8 ms/query**（重构前 35 / 111 / 283 ms）；
- 注入：每会话首轮 1 次 ≤1KB（≈300–400 token），修复前实测「每 15 秒一次」（6 轮 6 次）；
- 提炼：默认档不调模型；开启后每会话 ≤8 窗 × ≤12KB，每日 ≤20 万 token，超限计入"跳过"；
- 面板产物：`lib/nexus.html` ≈700KB（含内联 sourcemap）。

## 4. 已知短板（请重点批判）

1. **语义层是启发式**：否定/冲突/近义全靠 token 规则，无真正语义理解；xfail 里仍有 5 条真实缺陷（「切记记住」脚手架、选择问、"么"结尾误拒、繁体触发词、第三人称引述）；
2. **工具失败通道仍关闭**（`capture.toolFailure=false`）：修好需先做脱敏；
3. **身份判定仍可能过宽**：真实库里曾把子代理提示词判成 user 身份（24 条 user 中 17 条），收紧后仍需 golden 负例持续监控；
4. **`checkpoint` 提炼未做**：LLM 产出只能下次会话可见；
5. **分发与类型**：只有 github 源安装，未发 npm；无 `lib/types` 声明产物；
6. **bench 与生产形状不符**：golden 是确定性层；检索 holdout 仅 11 条且原子手工构造；
7. **面板产物偏大**（700KB 内联 sourcemap）；无 CSP。
