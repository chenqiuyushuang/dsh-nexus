## 结构（照搬 B）

```
顶部状态条：● 2 条进入上下文 | 603 B / 1.00 KB | 0 条待确认          ← 点开面板
└ 面板
  ├ 标题 记忆 + ✕
  ├ 模式三态（记录中 / 只看不记 / 已关闭） + 预算条（17 进入 · 9 未进入）
  ├ 统计行：今日写入 / 待确认 / 已拒收 / 注入次数
  ├ 标签页：归因 N · 记忆库 N · 回收站 N · 设置
  └ 内容区（可滚）
```

- **归因**（B 的核心）：按"进入上下文 / 置顶插队 / 用户显式声明 / 模型推断 / 未进入 · <原因>"分组，
  每组给条数与字节；卡片显示 标题 · 字节 · 置信度点 · 来源 · 作用域 · 置顶标；未进入的显示原因。
  误写记忆横幅带「查看 / 一键归档」。
- **记忆库**：搜索（命中 <mark> 高亮）· 状态筛选（全部/活跃/待确认/冲突/已归档/今日写入/仅用户明文/仅子代理）·
  作用域筛选 · 新增 · 批量栏（确认/归档/入回收站）· 点条目展开详情（原文 + 动作）。
- **回收站**：已归档列表 + 单条恢复 + 彻底清空。
- **设置**：置信阈值两个输入 + LLM 提炼器选择 + 运行状态（预算/占用/活跃/降级）+ 保存。
- 交互：`⋯` 菜单（编辑 / 复制 ID / 关联 / 置顶 / 归档 / 入回收站）、编辑弹窗（全文 + 置信度滑块 + 作用域）、
  新增弹窗、关联弹窗、Toast（带撤销）。

## 为支撑 B 新增的后端能力（都落盘、重启仍在）

| 接口/字段 | 说明 |
|---|---|
| `POST /nexus/api/mode` | 三种模式：`readwrite` / `readonly` / `paused`；写 store 的 `panelMode`，同时改调度器的全局模式（**立即生效**，不需要重启） |
| `/state.mode` | 当前模式（面板按钮的选中态） |
| `/state.stats` | 今日写入 / 待确认 / 已拒收 / 注入次数 |
| `/state.sourceCounts` | 用户明文 / 模型推断 / 子代理整理 的条数 |
| `/memory.items[].provenance` | 来源（B 的"用户明文 / 模型推断 / 子代理"三分法） |

模式的语义（与 `/memory session` 的会话级覆盖并存，会话级优先）：
- **记录中** `read-write`：既记也注入
- **只看不记** `write-only`：不记，但仍注入
- **已关闭** `pause`：既不记也不注入

## 与 B 原型的三处落地差异

1. **面板宽度自适应**：B 写死 `width:420px`；DSH 设置弹窗内容区实测 418px，改成 `100% + max-width`。
2. **入口**：B 是"点状态条开面板"，这里状态条常驻面板上方（设置项本身已经是入口，不需要两级）。
3. **数据全部接真**：B 原型里是写死的示例数据；这里接 `/nexus/api/{state,memory,mode,settings,models,neighbors}`。
4. （兼容）旧版服务未重启时没有 `mode/stats/provenance`，面板用本地数据兜底，不会显示成"未知/0"。
